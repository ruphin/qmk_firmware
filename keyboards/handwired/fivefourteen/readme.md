# fivefourteen

A handwired keyboard with a 5x14 matrix, driven by a QMK Proton C (STM32F303).

* Keyboard Maintainer: [ruphin](https://github.com/ruphin)
* Hardware Supported: fivefourteen v2 (Proton C)
* Hardware Availability: Handwired, one-off build

Make example for this keyboard (after setting up your build environment):

    make handwired/fivefourteen:default

Flashing example for this keyboard:

    make handwired/fivefourteen:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader by pressing the reset button on the Proton C.
